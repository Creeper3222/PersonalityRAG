编辑时可选择新的模型提供商；若发生变化，保存后会对该记忆库启动全量索引重建。

      

        
会话管理

        
管理用户会话状态和对话历史的缓存行为；平台捕获开关由适配器负责，本体负责 conversations.db 的储存与裁剪。

        

          
          
          
          
          
        

      

      

        
记忆召回

        
控制当前记忆库的库级召回语义；适配器或 API 调用方可在请求时单独传入嵌入候选条数，本体侧不再持久化同名设置。

        

          
          
          
          
        

      

      

        
记忆隔离设置

        
控制当前记忆库召回时是否按请求中的人格和会话字段过滤；具体 persona_id / session_id 由适配器或 API 调用方提供。

        

          
          
        

      

      

        
检索融合策略

        
BM25 和向量检索结果的融合参数（内部使用 RRF 算法）。

        

          
        

      

      

        
图记忆双路检索

        
启用后会同时维护文档路和图路，两边都支持关键词与向量检索，再统一融合召回结果。

        

          
          
          
          
          
          
          
          
          
          
          
          
          
          
          
        

      

      

        
重要性衰减

        
随时间逐步降低旧记忆的重要性，防止旧信息长期占据高权重

        

          
          
          
          
        

      

      

        
定期备份

        
每日自动备份记忆数据库，防止数据意外丢失

        

          
          
        

      

      

        
自动清理设置

        
定期清理时间久远且重要性低的旧记忆，控制记忆库规模
